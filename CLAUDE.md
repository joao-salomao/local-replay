# CLAUDE.md

## Commits

Write every commit message in English — subject and body.

This applies to commit messages only. The user-facing interface is Brazilian
Portuguese and stays that way: page copy, button labels, and the error messages
players see are all pt-BR. Code comments are English, as they already are
throughout `src/`. When a commit message quotes UI text (`GRAVAR`, `Lance`),
quote it as it appears on screen rather than translating it.
